# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, in full:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Fairflow is used in classrooms. In addition to the Covenant: never post, quote or link a
participant's in-game actions, survey answers or debrief remarks in an issue, PR or
discussion. Records in this repository are pilots or synthetic; keep it that way.

Enforcement contact: the maintainer listed in CITATION.cff.
